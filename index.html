Santé publique mondiale

Étude de la sous-nutrition mondiale

FAO — Nations Unies

Contexte & Objectif

Dans le cadre d'une mission pour la FAO, j'ai analysé les données mondiales de sous-nutrition de 2017 afin d'identifier les pays prioritaires et de quantifier le paradoxe alimentaire mondial.

Résultats clés

  • 535,7 millions de personnes sous-alimentées dans le monde
  • La planète produit suffisamment pour nourrir 101,7% de sa population
  • 9,3 milliards de personnes pourraient être nourries avec la production actuelle
  • Cartographie des pays prioritaires et étude approfondie du cas Thaïlande

E-commerce & Retail

Analyse des ventes en ligne

Librairie Lapage

Contexte & Objectif

Analyse de 2 ans de données e-commerce pour identifier les profils clients, les leviers de fidélisation et les catégories de produits les plus performantes.

Sécurité financière

Détection de faux billets par ML

ONCFM

Contexte & Objectif

Développement d'un algorithme de machine learning pour détecter automatiquement les faux billets de banque, avec mise en production d'un script Python sérialisé utilisable directement par les équipes métier.
